# v0.3 bootstrap status

## Implemented

The v0.3 client bootstrap contains four separate responsibilities:

1. ProcessLocator: finds/launches RDR.exe and reads its full image path.
2. GameBuild: reads PE headers and validates the x64 target requirement.
3. Injector: checks for the existing module, opens the target process, writes the DLL path, and uses the Windows LoadLibraryW remote-thread bootstrap.
4. client-main.dll: initializes logging, GameBridge, ClientNetwork, and a temporary bootstrap tick source.

## Important limitation

BootstrapTickSource is not the final RDR1 render/game tick.

It exists only as a safe development loop while the exact target RDR1 executable build and the correct engine update hook are verified.

Do not add RDR1 memory reads/writes to this temporary worker thread.

The next task is a verified Rdr1GameTickSource for the exact game build.
